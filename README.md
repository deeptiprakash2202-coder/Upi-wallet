# FinTech Backend

A backend application built using Spring Boot for a digital wallet system. The project implements secure user authentication, wallet creation, and account management using PostgreSQL.

## Features

### Authentication
- User Registration
- User Login
- Duplicate Email Validation
- BCrypt Password Hashing
- Spring Security Integration

### Wallet Management
- Automatic Wallet Creation on Registration
- Initial Wallet Balance = ₹0
- Wallet linked to a specific user
- Retrieve Wallet Information

### Database
- PostgreSQL
- Spring Data JPA
- Hibernate ORM
